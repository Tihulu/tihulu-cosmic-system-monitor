# Changelog

## 0.2.0 - 2026-08-23

- Replace the basic popup with a detailed scrollable live dashboard.
- Add 60-sample CPU/GPU usage and temperature history graphs.
- Add RAM, VRAM and network RX/TX history graphs.
- Add network throughput and interface reporting.
- Add CPU model, topology, average frequency, load average and uptime.
- Add live per-logical-core CPU usage bars.
- Add GPU model, driver, power and clock information for NVIDIA GPUs.
- Add swap usage details.

## 0.1.0 - 2026-08-23

- Initial COSMIC panel applet.
- CPU/GPU utilization and temperature.
- RAM and VRAM usage.
- NVIDIA and DRM/sysfs GPU support.
